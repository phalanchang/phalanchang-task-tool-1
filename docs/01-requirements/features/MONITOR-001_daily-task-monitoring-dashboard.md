# 要件定義書: デイリータスクモニタリングダッシュボード

## 要件ID
MONITOR-001

## 要件名
デイリータスクモニタリングダッシュボード機能

## 概要
ダッシュボード画面にデイリータスク（繰り返しタスク）の実行状況をモニタリングする機能を追加する。当日の進捗、今週の実績、先週との比較、個別タスクの成功率などを視覚的に表示し、ユーザーが習慣化の進捗を把握できるようにする。

## 背景と目的
- **背景**: 現在のダッシュボードは静的な情報のみ表示しており、デイリータスクの実行状況を把握することができない
- **目的**: ユーザーが自身の習慣化の進捗を可視化し、モチベーション向上と改善点の発見を促進する

## 機能要件

### 1. 当日の実行状況表示
- 本日のデイリータスク総数
- 完了済みタスク数
- 未完了タスク数
- 完了率（パーセンテージ表示）
- 獲得ポイント数

### 2. 今週の実行状況表示
- 今週のデイリータスク総数（延べ数）
- 完了済みタスク数
- 完了率（パーセンテージ表示）
- 日別の完了状況グラフ（棒グラフまたは折れ線グラフ）
- 週間獲得ポイント数

### 3. 先週比較機能
- 先週の完了率
- 今週との比較（増減をパーセンテージで表示）
- 改善/悪化の視覚的表示（色分け、矢印アイコンなど）

### 4. タスク別成功率表示
- 各デイリータスクの個別成功率
- 過去7日間の実行履歴
- タスクごとの連続実行日数（ストリーク）
- 成功率によるランキング表示

### 5. データ更新
- リアルタイム更新（タスク完了時に自動反映）
- ページリロード時の最新データ取得
- 日付変更時の自動リセット

## 非機能要件

### パフォーマンス
- 統計データの取得は1秒以内に完了すること
- キャッシュを活用し、不要なAPI呼び出しを削減

### ユーザビリティ
- モバイルレスポンシブ対応
- 直感的で見やすいUI
- ローディング状態の表示
- エラー時の適切なフィードバック

### 拡張性
- 将来的な分析機能追加を考慮した設計
- データエクスポート機能の追加余地

## 技術仕様

### API エンドポイント
```
GET /api/daily-task-stats
  レスポンス:
    - today: 当日の統計情報
    - thisWeek: 今週の統計情報
    - lastWeek: 先週の統計情報
    - taskBreakdown: タスク別の詳細統計
```

### データベース
既存のtasksテーブルを活用し、集計クエリで統計情報を生成

### フロントエンド
- React コンポーネントとして実装
- Chart.js または Recharts でグラフ表示
- カスタムフックで統計データ管理

## 制約事項
- 既存のデータベース構造を変更しない
- 現在のUIフレームワークとの一貫性を保つ
- パフォーマンスへの影響を最小限に抑える

## 成功基準
- ユーザーがデイリータスクの実行状況を一目で把握できる
- 統計情報が正確かつリアルタイムに表示される
- モバイルデバイスでも快適に利用できる

## リリース計画
1. Phase 1: 基本的な統計表示機能
2. Phase 2: グラフ表示とタスク別分析
3. Phase 3: 高度な分析機能（オプション）
